# Restaurant UI redesign — verified stage, 26 October 2026

This is a partial implementation, not completion of the full approved redesign.

## Source and scope

Branch: `feature/restaurant-ui-redesign-20261025`. The starting feature branch was behind the functional `main` baseline `0ff5b108ab5c0aedfbf05e5375aa57a345bf96c0`. Functional source/assets, backend source, migrations and tests missing from that branch were restored from that baseline. GitHub workflows were not changed. Restoring backend files does **not** deploy them or apply migrations.

New implementation: `manager-ui.js`, `manager-team-ui.js`, screen-scoped `manager-redesign-test.css`, and small hooks in `index.html`. The app uses only the existing test Supabase project `kskrkzxiaxesvghvvecp`. No production database, main branch, GitHub Pages deployment or separate Invoices project was modified.

## Implemented

- Compact original-logo administrative header, five-tab navigation, Home modules linked to existing actions, operational counts from the authorised dashboard, truthful unavailable roster/lateness totals.
- Operations menu, More menu and working Quick Actions dialog. Finance currently opens the existing supplier-invoice feature; it is not a financial dashboard.
- Team search and department/status filters, employee details, existing edit/access/status controls, masked PIN, employee shifts/time off queries and explicit unavailable audit history.
- Restaurant Settings tabs with current unit and available holiday information; no invented business contact data or enabled cross-unit switch.
- A 20-second API timeout without automatic write retries. Sign-out immediately hides all registered screens, including custom screens.
- Manager clock status supports the test API's active-shift payload when `manager.status` is absent. No time calculation or clock persistence logic was changed.

Existing Roster, Approvals, Staff Hours, Time Off, Stock, Kitchen, Invoices, Timesheets and Time Clock remain accessible. Their full approved internal-screen redesign is **not complete**.
